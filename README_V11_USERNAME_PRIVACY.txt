ComboApp V11 - Username privacy

1) Run COMBOAPP_USERNAME_PRIVACY_SETUP.sql once in Supabase SQL Editor.
2) Upload the contents of combo/ to GitHub Pages, replacing the old files.

Username visibility options:
- الجميع: everyone can see it.
- جهات اتصاله: only people saved by the owner as ComboApp contacts can see it.
- لا أحد: hidden from other users; the owner can still see their own username and can still see other users' usernames according to those users' settings.
