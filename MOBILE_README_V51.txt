ComboApp V51 — Mobile / iPhone / Android

This version keeps the existing ComboApp web app and makes it installable as a PWA on Android and iPhone/iPad.

Android (Chrome):
1. Open the live ComboApp URL.
2. Chrome menu → Add to Home screen / Install app.
3. Open ComboApp from the new icon; it runs standalone like an app.

iPhone/iPad (Safari):
1. Open the live ComboApp URL in Safari.
2. Share → Add to Home Screen.
3. Open ComboApp from the Home Screen; it runs standalone.

Notes:
- Supabase/auth and live GIF search still require an internet connection.
- A true store APK/AAB for Google Play and a signed IPA for the App Store require platform signing/build tools and developer accounts. V51 is the cross-platform mobile web-app build that can be installed on both systems from the same URL.
